# Pilot result map
This tree is independent of the current manuscript's 34 generated assets and RESULT_MAP.md.
The protocol lock was committed before measurement; every outcome is exploratory.

| Output | Generator | Inputs and verification |
|---|---|---|
| `results/known_controls.json` | `controls.py` | frozen protocol; known Q; fixed seeds; measurement-source hash; canonical record hash |
| `runs/*/profile.npz` | `measure.py` | four `targets.json` record/checkpoint hashes; original training graph/random X; frozen uniform subset; exact gradients and distances |
| `runs/*/q*.npz` | `measure.py` | profile; original signs; seeded stress sampler; immutable query/radius/strength/draw keys |
| `runs/*/complete.json` | `measure.py` | SHA-256 of all 416 input arrays; original full-test logit hashes before/after; source and lock hashes |
| `training/*/profile.npz`, `q*.npz` | `train_control.py` | independent consensus splits; validation-only selection; true-Q completions; local exhaustive single flips |
| `training/*/complete.json` | `train_control.py` | split-array hashes; stored selected checkpoint; raw-file hashes; original logit hashes before/after |
| `results/report/summary.json`, `REPORT.md` | `collect.py` | complete network/training records and all referenced raw hashes; known-function record |
| `results/report/network_effects.{pdf,png}` | `collect.py` | primary network probability RMSE curves in summary |
| `results/report/control_comparison.{pdf,png}` | `collect.py` | known consensus failure fractions, analytic conditional variance, trained true-Q completion RMSE |
| `results/report/MANIFEST.json` | `collect.py` | hashes of every report output and source input record; collector hash |

Regenerate into a different directory:

```bash
PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  python3 collective/collect.py --out /tmp/www-collective-report-check
```

The collector rejects missing completion records or mismatched raw-file hashes. It never writes to the
paper. The two learned-control checkpoints live in the campaign's content-addressed object store.

`training/CHECKPOINTS.json` maps bundled `training/*/selected.pt` files to the selected checkpoint hashes
in their completion records. `results/verification.json`, generated by `verify.py`, independently replays
all six checkpoints' full-test logits, a gradient row and seeded intervention draws. Additional post hoc
descriptive reporting is explicitly recorded in DEVIATIONS.md.
